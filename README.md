# Supply Chain and Inventory Management Dashboard

## Overview
An Excel based project analyzing supply chain operations, inventory levels, and supplier delivery performance.

## Key Features
- KPI dashboard showing total orders, on time delivery percentage, total inventory, and total spend.
- Supplier on time delivery performance chart.
- ABC inventory classification based on annual usage value.
- Inventory health analysis using days of supply.
- Excel formulas for operational metrics and analysis.

## Tools Used
- Microsoft Excel
- Excel formulas
- Charts and data analysis

## Dataset
This project uses sample historical order and inventory data.
